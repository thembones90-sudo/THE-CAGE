# THE CAGE / LEGENDARY ARENA V2
## Status
Isolated, reviewable visual artwork. NOT integrated into live gameplay and not a real score or match engine.
Owner direction: original premium industrial underground 3v3 arena, street-football grit, gunmetal steel enclosure, original legendary golden football, hard industrial lighting, steel-chain net goals, no literal ship branding.

## Open
Open index.html in Chrome/Edge locally, or run a static HTTP server from the project root and visit /design/qwen-30b/arena/index.html.
No external scripts, fonts, images, packages or network dependencies are required. ?arena=gold selects the Golden variant; ?players=hide hides the demonstration elements.
Buttons toggle Iron Pit / Golden Arena, pause/resume illustration motion, demo marker visibility and playback pace. The 0:0 board is MOCK DATA.

## Files / art layers
- arena.svg: original Iron Pit. 1200x650 top-down base; groups foundation, surface, surface-scuffs, markings, cage-frame, chain-net-left/right, chain-links-left/right, goal-left/right, lights, environment-labels, variant-spill.
- arena-golden.svg: same playable geometry; separately rendered warmer floodlight and gold trim treatment. Not a CSS tint.
- relic-ball.svg: independent 200x200 premium metal ball with original engraved geometric panels.
- iron-maw-detail.svg: zoomed manufacturing/detail study of individual oblong steel chain links and reinforced frame.
- script.js: illustrative motion only, no football outcomes, team scores or match events.
- styles.css: dark Industrial Underground preview, desktop/mobile, reduced-motion support.
- arena-v2-iron-desktop.png, arena-v2-golden-desktop.png, arena-v2-mobile.png: actual locally rendered Chrome screenshots.

## Coordinate geometry (never alter without coordinating with viewer)
SVG world: 1200x650. Active turf rectangle x = 110..1090, y = 70..580 (980x510).
Normalized position (u,v) in [0,1]: X = 110 + 980u, Y = 70 + 510v.
Engine 4x3 cell center c,r: u=(c+.5)/4, v=(r+.5)/3. Validate team-frame mapping against actual T3 telemetry before integration.
Left goal plane x ~=109, right plane x ~=1091, each mouth y=242..408. Chain net illustrations extend OUTSIDE live pitch x=23..101 and x=1099..1177. Markers and ball draw above the background. Never infer scoring from this geometry in the renderer; accept authoritative game logs.
SVG groups are independently addressable if a renderer inlines/parses SVG; HTML demo displays base as img for reliable offline viewing. Future net shake or lighting animation must render those separate groups rather than mutate the current base image directly.

## Technical boundaries
- Visual motion is a demo, never an actual football simulation.
- Gold accents restrained to ball and rare steel details; surface stays dark.
- Chains and goals are visual only; collision and responses belong to actual simulation.
- All assets scalable vector, no image-hosting dependencies, no logos or cloned ball patterns.
- Full pitch with both goals fits on 500px mobile Chrome viewport.
- Live match viewer and engine remain unchanged. This artwork awaits owner approval before integration.
